# hello 🌏

**工程明日** · engineering tomorrow

founder of [orbyn](https://orbyn.dev): a family of local-first apps that sync end to end under one account, built so agents can work in them safely. still building, nothing has launched yet.

## line-up

- [**orbyn planner**](https://github.com/orbyn-dev/orbyn-planner): tasks, lists, projects and calendar, offline and encrypted end to end.
- [**orbyn notes**](https://github.com/orbyn-dev/orbyn-notes): encrypted notes and pages that link to your tasks and events.
- **orbyn studio**: films, lyric videos, demos and social posts, made from code with your own agent.
- [**orbyn engineering**](https://github.com/orbyn-dev/orbyn-engineering): a workspace for coding agents, with memory, review and the skills library built in.

## open source

- [**orbyn skills**](https://github.com/orbyn-dev/orbyn-fullstack-skills): a full harness system for codex and claude code, built on a portable skill set.
- [**orbyn engine**](https://github.com/orbyn-dev/orbyn-engine): the rust core every orbyn app shares: accounts, encrypted sync and keys.
